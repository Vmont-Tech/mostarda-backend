# State Machines — Execution Model

Transições são autorizadas exclusivamente por Commands do owner e registradas por eventos. Estados finais não aceitam transição, salvo criação de Aggregate/linha compensatória explicitamente definida.

| Máquina | Estados e transições válidas | Finais/proibidos | Recuperação |
| --- | --- | --- | --- |
| Campaign | `DRAFT → READY → PUBLISHED → ACTIVE ↔ PAUSED → COMPLETED`; `DRAFT/READY/PUBLISHED/ACTIVE/PAUSED → CANCELLED`; `PUBLISHED/ACTIVE/PAUSED → EXPIRED`. | Finais: `COMPLETED`, `CANCELLED`, `EXPIRED`. Proibido publicar sem criativo aprovado ou retomar final. | Pausa preserva Slots executados; cancelamento revoga futuros. |
| Slot | `ALLOCATED → DELIVERED`; `ALLOCATED → REVOKED/EXPIRED`; `DELIVERED → EVIDENCED`. | Finais: `REVOKED`, `EXPIRED`, `EVIDENCED`. Proibido executar revogado/expirado ou reatribuir Slot. | Falha de Edge mantém `ALLOCATED` até expiração; tentativa é identificada. |
| Playback | `IDLE → PREPARING → PLAYING → FINISHED`; `PREPARING/PLAYING → INTERRUPTED/FAILED`; `INTERRUPTED → RECOVERING → PLAYING/FAILED`. | Finais: `FINISHED`, `FAILED`. Proibido `FINISHED` sem duração/checksum ou iniciar sem Slot. | Supervisor cria nova tentativa; tentativa falha não vira Evidence. |
| EvidenceRecord | `BUILDING → PENDING_VALIDATION → VALID`; `PENDING_VALIDATION → INVALID/DISPUTED`; `VALID/DISPUTED → REVERSED` somente compensatoriamente. `VALID → ANCHOR_PENDING → ANCHORED` é estado de ancoragem associado. | Finais de validade: `INVALID`, `REVERSED`; `ANCHORED` é condição para Settlement. Proibido `VALID` sem validação e mutar registro. | Retry de validação/âncora; disputa bloqueia parcelas afetadas. |
| Settlement | `OPEN → CALCULATING → AUTHORIZED → EXECUTING → CLOSED`; `OPEN/CALCULATING/AUTHORIZED/EXECUTING → BLOCKED`; `BLOCKED → CALCULATING/AUTHORIZED`; `CLOSED → COMPENSATING` para linhas novas. | `CLOSED` é imutável; proibido fechar sem elegibilidade. | Reprocessa por idempotência; compensação não reabre histórico. |
| SplitShare | `PENDING → READY → PAID`; `PENDING/READY → BLOCKED/UNCLAIMED`; `READY → FAILED → READY` quando retry autorizado. | `PAID` é final; `UNCLAIMED` permanece recuperável por política. Proibido redistribuir share. | Retry por tentativa; chargeback cria recuperação, não reescrita. |
| TV | `REGISTERED → PROVISIONING → ACTIVE ↔ SUSPENDED`; `ACTIVE/SUSPENDED → MAINTENANCE → ACTIVE/SUSPENDED`; qualquer não final → `DECOMMISSIONED`. | `DECOMMISSIONED` final; proibido ativar sem provisionamento/health. | Suspensão preserva identidade; rollback de Edge não altera TV. |
| Edge | `UNINSTALLED → INSTALLING → HEALTHY`; `INSTALLING/HEALTHY → DEGRADED/UPDATING`; `UPDATING → HEALTHY/ROLLING_BACK`; `ROLLING_BACK → HEALTHY/FAILED`; `FAILED → INSTALLING`. | Não há final enquanto TV ativa; proibido atualizar sem pacote assinado. | Health gate e rollback para versão saudável. |
| PlayerSession | `IDLE → PREPARING → PLAYING → COMPLETED`; `PLAYING → DEGRADED/FAILED`; `DEGRADED → PLAYING/FAILED`; emergência: `PLAYING → PREEMPTED → PLAYING/COMPLETED`. | `COMPLETED`, `FAILED`; proibido sobrepor composição sem prioridade. | Supervisor reinicia sessão; restaura Canvas compatível após emergência. |
| InsuranceClaim | `FILED → UNDER_REVIEW → APPROVED/DENIED`; `APPROVED → REPAIR_AUTHORIZED/REPLACEMENT_AUTHORIZED → SETTLED`; `FILED/UNDER_REVIEW → WITHDRAWN`. | `DENIED`, `SETTLED`, `WITHDRAWN`; proibido liquidar sem cobertura/reserva. | Evidência complementar retorna a `UNDER_REVIEW`; nova claim não altera decisão final. |

Transições de estado desejado de Edge são separadas da máquina operacional: `DesiredState` é publicação de intenção, `CurrentState` é declaração do Edge e `ObservedState` é derivação Cloud; o reconciliador não inventa estado, apenas emite Commands válidos.
