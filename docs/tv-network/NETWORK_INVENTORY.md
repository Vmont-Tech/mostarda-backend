# Network Inventory

Network Inventory é a visão derivada e versionada da frota: TV, Venue, proprietário, geolocalização, Display, MiniPC, Edge, conectividade, Capabilities, versões instaladas, health, estado operacional e histórico de substituição.

Inventário é leitura operacional; não é fonte de estado para outro Aggregate. Ele é atualizado por eventos do Registry, Health, Capability e Maintenance, preservando momento observado e origem. Nunca inclui anúncios, Campaigns, preços, Evidence, Settlement ou dados financeiros.
